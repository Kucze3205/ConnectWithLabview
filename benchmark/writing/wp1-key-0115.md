## Coverage of obligations

The JSON indexes **429 source obligations**: every scalar/empty-container pointer of the selected `method.json` sections (revision, status, authority, claims, existing/new requirements, common, comparison, coverage) and the WP1 task (334), plus every non-blank, non-heading protocol line (95). Each maps to one or more of 23 rules (`R-*`). Lines about other families or native diagram operations are marked `not-applicable-to-WP1` with a reason; the full-goal gap stays visible. The checker re-derives this inventory from current sources and fails on any missing, extra, duplicate or re-pinned obligation. Enumeration is not independent approval: the **semantic** mapping from obligation to rule still needs the separate checker.

Unsupported extra claims and contradictions are covered by `R-mapping` and `R-assessment` (extra-claim ledger, duplicates credited once, negation retains both assertions, false extras make the dimension incorrect, unverified extras prevent correct). **C1 remains open.** Structured flags, hashes, byte comparison or substring checks cannot settle arbitrary narrative truth; a human adjudicates semantic equivalence, extras, contradictions and original/output citations. Honest limitations: no reader-fidelity denominator exists yet (`reading_fidelity: null`), no native documentation is pinned, and unknown native outcomes stay separate (`unexecuted`/`unverified`), never inferred from XML declarations such as root `LVVersion="20008000"`.

## Checker and its limits

`python3 -I benchmark/writing/check_wp1_key_0115.py` reads repository files only (no `.session`, no `LABVIEW_ENVIRONMENT`) and writes nothing. It re-derives obligations from current `method.json`/`protocol.md`, re-resolves the original (SHA256, unique XML match, byte offset, line, derived output hash), checks every input pin and Git blob, and runs in-memory counterexamples for missing/duplicated IDs, bad locators/pins and unsupported native/approval/readiness/allocation promotions. Passing means package integrity and source coverage only. It does not certify narrative truth, C1 adjudication, native behavior, isolation, independent approval or trial readiness.
