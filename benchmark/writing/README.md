## Reproducible design check

Run from the repository root:

```text
python3 -I benchmark/writing/verify_method.py
```

The stdlib checker reads only adjacent `method.json` and [controls.json](controls.json), accepts no external input and writes no files. Neither `LABVIEW_ENVIRONMENT` nor `.session/` is needed. It checks fixed task/requirement inventories, required fields, arithmetic/inversion consistency and dimension/coverage declarations, then checks hand-authored fictional graph snapshots against separately stated requirements. There is no LabVIEW parser, writer, benchmark runner or production evaluator.

Positive controls retain creation, modification, source-only modification with unavailable rebuild, and a matched but unexecuted pair. A valid fictional `x+1` graph passes its own request but fails the `x+2` request, exposing a constant writer. Forty-four in-memory mutations must reject for exact asserted reasons: the original 35 controls for no-op/changed-bytes-only, wrong graph/type, unintended edits/files, missing output, version drift/unknown version, unsupported artifact, wrong answers/citations/extras, invented native success, overwritten originals, creation overwrite, mismatched pair inputs/budgets, missing arm/accounting, method overclaims and missing fields, missing compiled source, invented rebuild and mismatched source/build linkage; plus nine controls correcting review #485. Two preserve originals at `SYNTHETIC-v0` while outputs and frozen expectations remain at `SYNTHETIC-v1`; ordinary and source-rebuild modifications must both reject for `version-drift`. Modification checks original-to-output version equality as well as the frozen version; creation uses its requested version. Seven controls independently delete each mandatory pair setting from the frozen dictionary and both arms, requiring `pair-setting-required`. The mandatory names (`request`, `originals`, `allowed_inputs`, `model`, `budgets`, `key_revision`, `repetitions`) map the documented paired obligations in protocol lines 79–84 and the runner contract to this bounded synthetic representation; equality among incomplete dictionaries cannot satisfy them. Matching values, matching key sets and paired-arm invariants remain checked. The fixed control inventory prevents silently dropping a rejecting test. This is a bounded contract check, not a complete semantic checker; coordinated edits to fixtures and checker still need independent review.

[verification.json](verification.json) records the actual check and input hashes; [input-pins.json](input-pins.json) records baseline identity and preserved evidence hashes. [review-corrections.json](review-corrections.json) pins review #485, the starting/reviewed identities and six hashes, protected-byte checks, and exact before/after counterexample mutations and reason codes. Passing means design consistency only. Synthetic graph fields are not decoded LabVIEW objects, `SYNTHETIC-v1` is not a real save version, and none of these controls produces native evidence or authorizes measurement.
