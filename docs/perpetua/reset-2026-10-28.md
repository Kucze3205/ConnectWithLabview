## Lessons for the setup map

1. **No model session produced work in iterations 0000 and 0001.** Orchestrator #27: 169 attempts, 0 turns,
   crashed. The runner stopped 14 times on a pending read-only action. Audit #43: 1.17M `gpt-5.6-luna`
   input, 0 turns, crashed. Check that every provider route produces an accepted turn before arming.
2. **The cost is turns × prompt size.** Each turn is a fresh stateless call that resends the role prompt and the
   compacted history. Orchestrator #27 used 165 turns and #44 used 90. Iteration 0 used 2.15M input and 2.61M
   cache write; iteration 1 used 1.84M input and 2.52M cache write.
3. **Failed attempts cost tokens without results.** The codex fallback spent 2.15M (#27) and 0.67M (#44) input
   for under 5k output. Do not route to a candidate that has never produced an accepted turn. Stop after 2–3
   zero-turn attempts.
4. **Iterations 0003–0005 failed with the shaper at its 30-turn cap.** Each spent about 0.5M `gpt-6.1-sol` input
   for about 2k output and wrote no task graph. Cutting turns alone did not make the orchestrator finish. Consider a
   smaller shaper or a deterministic rule (`shaper` in `policy/params.yml`).
5. **The audit crashed in both iterations that ordered it** (#43, #55).
6. **Write-path mismatch:** the orchestrator was told to write `.session/report.md`, but its profile allowed only
   `journal/**`.
7. **The orchestrator has no shell,** so it cannot run a task's verification command. Shaped tasks need their own
   `## Verification`, and work sessions run it.
